Setup:

For Raid Leader to do: 

1. Setup an Ably account
2. Create an App with a 'Pub/Sub' type
3. It will generate two keys:
     a) The 'Root' key is the 'leader' key, the Healers & designated Tank will need to use this key
     b) The 'Subscribe Only' key is the 'viewer' key, everyone else will use this key

For everyone else:

1. Download the latest Lura.Overlay.x.x.x.exe
2. Run it
3. Click the Cog in the top right
4. Enter the appropriate key and click 'Save & Connect'
5. Viewers can optionally change the layout;
   
   'Line' will display the order the symbols appear Left -> Right,
   
   'Cock' will display the order the symbols would be around the boss (this is what most people prefer)
6. Leaders will need to select their difficulty, and if you select Mythic, you will then need to select whether you are a Healer or a Tank.
7. Click the Cog again to close the settings

How to input:

For Heroic, only one leader needs to input, but if multiple people do, the display will show the symbols with the most inputs for each slot. 
This means that if three people are inputting, and one person gets it wrong, it should still show the correct order.

For Mythic:

The Tank will be inputting the 'upstairs' realm, or symbols 1 & 4. The app will only allow those slots to be filled by the Tank.

The Healers will get prompted by what colour they are; Red or Blue. Once they have selected their colour, they will be given the appropriate slots 
for the input. If a Healer misclicks their realm the 'Clear Phase' button will let them re-select their realm.

Whenever anyone clicks the 'Clear All' button, all inputs will be cleared, along with what realm the Healers have selected in preparation for the next Memory Game.
Lastly, there is a Backspace button next to the symbol input for all users, this will undo the last input that you specifically have done.
